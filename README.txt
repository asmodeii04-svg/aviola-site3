АВИОЛА.NET — HTML/CSS/JS шаблон сайта

Состав:
- index.html — главная страница
- news.html — Новости
- iptv.html — IPTV
- resources.html — Ресурсы сети
- subscribers.html — Абонентам
- geography.html — География сети
- about.html — О провайдере
- assets/style.css — стили, тёмная тема, анимации, адаптивная вёрстка
- assets/script.js — переключатель темы, мобильное меню, анимированный фон
- assets/favicon.svg — иконка сайта

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Переходы между страницами работают через меню, карточки и ссылки.

Тёмная тема:
- по умолчанию совпадает с темой устройства;
- кнопка в правом нижнем углу переключает тему, выбор запоминается в браузере.
Цвета обеих тем лежат в начале assets/style.css, в блоке «Тема».

Что нужно заменить перед публикацией:
- адрес кнопки «Личный кабинет» (в каждом html-файле ищите TODO);
- тексты, контакты, фактические сведения, карту покрытия, IPTV-данные и изображения
  на официальное содержимое проекта.

Для публикации в интернете загрузите все файлы и папку assets на хостинг,
сохраняя структуру каталогов.
